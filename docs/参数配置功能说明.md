# Qbot 参数配置功能说明

## 功能更新内容

### 1. 数据存储选项修改

#### 1.1 本地 CSV
- 选择"本地csv"选项后，自动弹出目录选择框
- 选择目录后，该路径将用于存储 CSV 数据文件
- 配置保存在 `sys_para.json` 中

#### 1.2 PostgreSQL 数据库
- 数据存储选项改为"postgresql"
- 选择后弹出配置对话框，需要填写：
  - **地址**: PostgreSQL 服务器地址（如 localhost）
  - **端口**: 端口号（默认 5432）
  - **数据库**: 数据库名称
  - **用户名**: 登录用户名（默认 postgres）
  - **密码**: 登录密码（临时存储）
  - **表名**: 数据表名称
- 点击确认后自动测试连接并执行查询：
  ```sql
  SELECT * FROM 库.表 ORDER BY trade_date
  ```
- **注意**: 密码仅临时存储在内存中，程序关闭后丢失

#### 1.3 Tushare 数据源
- 选择"tushare"数据源后，自动弹出 API Key 输入框
- 输入 API Key 后临时存储（程序关闭后需重新输入）
- 临时文件存储在 `qbot/common/configs/temp_tushare_token.txt`
- 程序退出时自动清理临时文件
- **注意**: 如果已经设置过 API Key，会提示是否重新输入

## 代码使用示例

### 在其他模块中获取配置

```python
from qbot.common.temp_config import (
    get_tushare_api_key,
    get_postgresql_config,
    get_csv_path,
    get_data_store_config,
    query_postgresql_data
)

# 获取 Tushare API Key
api_key = get_tushare_api_key()
if api_key:
    import tushare as ts
    ts.set_token(api_key)
    pro = ts.pro_api()

# 获取 PostgreSQL 配置（包含密码）
pg_config = get_postgresql_config()
if pg_config:
    print(f"Host: {pg_config['host']}")
    print(f"Database: {pg_config['database']}")
    print(f"User: {pg_config['user']}")

# 获取 CSV 路径
csv_path = get_csv_path()

# 获取完整数据存储配置
data_store = get_data_store_config()
if data_store['type'] == 'csv':
    path = data_store['path']
elif data_store['type'] == 'postgresql':
    config = data_store['config']

# 直接查询 PostgreSQL 数据
df = query_postgresql_data(limit=100)
```

## 配置文件说明

### sys_para.json 新增字段

```json
{
    "data_store_config": {
        "type": "本地csv",
        "path": "D:/Qbot/data"
    },
    "data_source": "tushare",
    "postgresql_config": {
        "host": "localhost",
        "port": "5432",
        "database": "",
        "user": "postgres",
        "table": "stock_data"
    }
}
```

## 依赖安装

使用 PostgreSQL 功能需要安装 psycopg2：

```bash
pip install psycopg2-binary pandas
```

---

## 安全说明

1. **Tushare API Key**: 仅临时存储，程序关闭后自动清理
2. **PostgreSQL 密码**: 仅保存在内存中，不写入配置文件
3. **临时文件**: 存储在 `qbot/common/configs/temp_tushare_token.txt`，程序退出时自动删除

---

## 注意事项

1. 首次使用 PostgreSQL 功能前请确保：
   - 已安装 psycopg2: `pip install psycopg2-binary`
   - PostgreSQL 服务器可正常连接
   - 数据表已创建且包含 `trade_date` 字段

2. Tushare API Key 每次重启程序后需要重新输入

3. CSV 目录需要具有读写权限

4. **Tushare API Key 输入问题已修复**: 现在选择 tushare 后会自动弹出输入框，使用 `wx.CallAfter` 确保对话框正确显示。
